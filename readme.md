# my-first-repo

我第一次用 Git 推送到 GitHub 的仓库。

## 关于这个仓库

- 作者：Fang（GitHub: ByeMonday）
- 用途：练习 git 的基本流程 `init → add → commit → push`
- 建立时间：2026-11-03

## 我学会的命令

| 命令 | 作用 |
|---|---|
| `git init` | 把这个文件夹变成 git 仓库 |
| `git add .` | 把改动放进暂存区 |
| `git commit -m "说明"` | 生成一次提交 |
| `git push` | 把提交推到 GitHub |
| `git status` | 看当前状态 |
